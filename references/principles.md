# 编辑原则与适用边界

1. 取舍：删除同义重复与用户允许省略的铺陈；条件、限制和不同建议不是重复。完整保留也可以是正确选择。
2. 节奏：在阅读受阻处调整，保留有效的排比、停顿和统一结构；不能靠随机断句制造人味。
3. 判断：保持原文立场及确定性。中立描述不需要补好恶，技术评审的排序也须有原有依据。
4. 具体：只整理已有细节。没有材料时保留抽象表达，不补日期、数字、业务名或经历；匿名不等于空洞。
5. 温度：保留已有情绪，不把“我愣住了”作为通用替换。克制文章与说明书都可以自然。

这五项是编辑观察角度，不能推断内容来源。样例里的具体表达只适用于该样例提供的材料。

## 净收益如何判断

先核对信息与关系，再看是否更容易读懂。把因果终点、否定或条件改掉，不能用顺口补偿。若只是风格偏好且用户未要求改变，保留原文。比较有疑问时提供建议，不强行执行。
