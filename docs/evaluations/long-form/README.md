## 如何理解结果

noai 在本轮两组评审中均为100分，6篇的双评均分均为100；相对普通改写，逐例5胜1平，平均高1.98分。仅描述这批样本结果，不推广为全场景胜率。

差异主要落在细微语义、情绪层次与编辑克制。修伞散文中，noai 保留“可能不必在某一个早晨全部完成”及“为什么有资格惦记”；部分方案将前者改成更确定的告诫，或删掉后者的关系迟疑，评分证据可逐项展开查看。

成熟活动说明中，七个方案两组评审全部100分，说明该例未区分出方案优劣。数字与流程保留也不是 noai 独有：本轮所有方案均未被两组评审标记严重错误。

noai 的六份输出字符数相对原文变化约为0%—10%，散文仅小幅调整。当前证据更支持“少改错、保住原意和声音”，不能替代对重度模板腔、篇章重构或真实读者偏好的测试。

## 测试方法

本轮为中文长文专项：6 篇原创模拟材料，6 个 Skill 加无 Skill 基线，共 42 份新生成改稿。原文由未读取参赛规则和既往结果的两个独立上下文创作，并在测试前检查任务与保留要求是否有据。输入及规则随后冻结。每方案一个独立生成上下文，方案内6篇共享上下文；按各 Skill 自身入口读取配套参考，不改参赛规则。所有方案使用同样的任务和可见保留要求。

生成与两组评审均显式配置为 gpt-6-astra medium，以调用配置为依据，未另行核验服务端身份。两组评审互不读取对方评分，每组3个独立上下文各审2篇原文的全部匿名候选，不接触方案身份或规则。每份改稿获得两次评分，共84份评分记录。采用相同 rubric 1.0.0，十维各0—4级，加权满分100；先取每例两位评审的平均，再对6例求均值，未调整权重。严重错误列按任一评审标记计数，不代表已经人工裁定。

各方案均分为96.35—100分，84份评分中48份为满分，存在明显高分聚集；100分仅表示两位模型评审未按当前量表扣分，不代表文本完美。原文已有大量具体事实、自然叙述和成熟段落，任务也明确列出保留要求，因此更偏向检验长文保真与编辑克制；不能据此推断对重度模板稿的去味收益。本轮没有对原文另行评分，无法用这些成绩计算编辑前后的质量提升。这是维护方组织的模拟任务评测，不是第三方认证或真实读者研究。只有单次生成；双评验证评分差异，不等于重复生成验证。样本作者、执行者和评审均使用同一模型配置，可能存在共同偏好。本轮检验长文假设，不证明短文、其他语言或跨模型优势。样本少且分差可能很小，不据此宣布统计显著胜出。不评估 AI 检测器通过率，字数缩减也不直接计为质量提升。
