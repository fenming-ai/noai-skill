## 计算方法

6篇原创模拟长文加1篇653汉字的中篇，6款Skill与普通改写基线，共49份改稿、91份评分记录。生成与评审配置均为gpt-6-astra medium。长文每份有两组匿名评分；中篇五个方案沿用已完成的输出和单次评分，shuorenhua与sepia按相同原文、任务及rubric补齐输出与单次匿名评分。采用rubric 1.0.0及原权重，每篇先取其评分均值，再对七篇等权平均，即（长文均分×6＋中篇分数）÷7。不按评审次数给样本加权，不改动既有评分。

## 适用范围

本报告是跨批次的描述性汇总，不是七个方案同轮重新生成。中篇曾参与规则开发且成绩已被观察，不是独立留出样本；补齐方案与既有五个方案的评审上下文不同。作者、执行和评审采用同一模型配置，单次生成且没有真人盲评。长文原稿相对成熟，分数集中在高位；分差很小，不能证明统计显著或普遍优势。原文外部事实未经本实验核实；测试编辑忠实性，不提供职业或政策建议。

## 全文与来源

六篇长文为原创模拟材料，可在 HTML 对照页查看。中篇来自 C-ReD 的固定版本，公开版只展示来源与汇总分数；由于未确认正文再分发许可，不包含该篇原文、改稿与引用原文的评审证据。本地评测资料保留完整对照。
