# 推荐文案：读者熟词与真实用途的开发检查

范围：本次新增教学对照的编辑自检，不是独立模型评测，不报告胜率。

- 输入：文章 AI味很重，请帮我推荐改稿工具。
  旧规则已有“用途优先”，但未明确提醒保护读者已用词；失败稿写成“清套话”。候选沿用“去 AI味”，没有把问题缩成固定句式。普通换词式润色仍可能写“清理模板化表达”，不足以满足本次语气。编辑判断：候选保留问题范围。
- 输入：根据历史文章提炼风格，实际交付是风格文档。
  失败稿称“写作说明书”；候选直说“从历史文章蒸馏写作风格”，并保留文档交付。不能扩成“自动训练模型、安装 Skill”。编辑判断：能力更清楚，交付不夸大。
- 保留例：这份设备说明书有三处错误；那段致辞重复了三句套话。
  原文两处术语均准确，候选应原样保留，不能替换成 Skill 或 AI味。编辑判断：新增样例有场景边界，不是禁止词表。

限制：以上是开发者的同场景分析；未调用独立模型跑旧版／新版／普通改写，不作为正式版本效果证明。
