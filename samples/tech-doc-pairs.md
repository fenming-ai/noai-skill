# 技术文档曲子库

> 以下为教学示例，不是实测或可直接套用的补写。具体技术、数字、日期、经历、代码行为和风险须有当前材料支持；缺少依据时只保留判断方向，不新增事实、不删必要信息、不改变程序语义。

> 技术文档/评审报告/设计文档 的 AI 味 → 人味 对比对。
> 每首曲子 = AI 默认输出 + 人味改写 + WHY + 记住什么。
> 不是从某份具体文档抄的，是从 AI 生成技术文档的共性模式里抽象的。
> 技术文档不需要"我愣了一下"的体感，需要准确+取舍+判断+具体。

---

### 曲子 1：[有取舍] 场景全展开 vs 主动砍

AI 味：
```
5 个场景全部展开，每个场景都从第一步到末步完整写：
场景一（构建方7步 + 使用方8步 + 专属补点表 + 案例数字 + 证据锚点）
场景二（构建方9步 + 使用方8步 + 专属补点表 + 案例数字 + 证据锚点）
场景三（构建方11步 + 使用方8步 + 专属补点表 + 案例数字 + 证据锚点）
场景四（构建方8步 + 使用方8步 + 专属补点表 + 案例数字 + 证据锚点）
场景五（构建方8步 + 使用方7步 + 专属补点表 + 案例数字 + 证据锚点）
```

人味：
```
3 个场景完整展开（场景一/二/三，差异最大）。
场景四压成一段话："和场景一结构一致，区别只在 X 和 Y，补丁 3/4 覆盖。"
场景五砍掉不展开："和前四个重叠太多，核心差异点已在补丁表覆盖。"
```

WHY：
5 个场景全展开是统计最可能的"全面性"——AI 不知道该删什么就全留着。
面面俱到 = 没有取舍 = AI 味。人知道读者看到第 3 个场景已经理解套路了，
会主动压缩重复的、砍掉重叠的。"我选择不展开这个" = 取舍 = 人味。

记住什么：
技术文档最重的 AI 味是"结构模板重复"。每个 section 一样长、一样结构、一样收尾。
人写东西有快慢——重要的展开，不重要的压扁或砍掉。

### 曲子 2：[有节奏] 模板化收尾 vs 变化收尾

AI 味：
```
每个 section 结尾都是同一个模式：
[案例数字框] 某场景的具体数字...
[证据锚点] 来源文件名...

5 个 section × 同一个 [案例数字] + [证据锚点] 骨架。
```

人味：
```
场景一正常收尾：案例数字 + 证据锚点
场景二换一种收法："这个场景的数据是合成的，真实数据不出域。"
场景三不单独收尾，结论直接写进正文："...违约率 1.5%→1.9%，这段数字本身就是结论。"
场景四收尾带判断："注意：N-1 校验是硬门槛，不是可选项。"
```

WHY：
每个 section 用一模一样的收尾模式 = 过度一致 = 匀速 = AI 味。
AI 默认每个 section 给同样的收尾，因为统计上最安全（不遗漏信息）。
人写东西会变花样——这个场景重要就展开说，那个场景数据敏感就标注一句，
有的结论直接融进正文不需要单独包。

记住什么：
收尾不要模板化。每个 section 的结尾应该由这个 section 的内容决定，
不是由"文档模板"决定。变化收尾 = 有节奏 = 人味。

### 曲子 3：[有判断] 无判断汇总 vs 有判断结论

AI 味：
```
共识速览表：5 个领域各自一行，正反两面都给，无判断：
领域A | 认可：X | 硬伤：Y
领域B | 认可：X | 硬伤：Y
领域C | 认可：X | 硬伤：Y
收敛信号：4/5 领域点名同一个问题。
（只汇总不判断：哪个最严重？哪个先改？不说）
```

人味：
```
先给判断，再给依据：
"最该先改的是缺口挂起——4/5 领域点名它，不是个别场景挑刺，是通用设计的系统性缺口。
其他 7 条按影响面排序见下表。"

表格里标粗区分优先级：
领域A | 认可：X | 硬伤：Y（P1）
领域B | 认可：X | 硬伤：Z（P0，涉密红线）
```

WHY：
"5 个领域各自一行正反两面"是统计最可能的"中立汇总"——AI 默认不偏不倚。
但技术文档的读者要的是判断：哪个最严重？哪个先改？
只汇总不判断 = 没有立场 = AI 味。人有好恶，会说"这个最该先改"。

记住什么：
技术文档不需要"我愣了一下"的体感，但需要"这个最该先改"的判断。
有判断 = 有立场 = 人味。汇总不是罗列，是排序+标注+给结论。

### 曲子 4：[有取舍] 面面俱到的"挑战与展望" vs 砍掉

AI 味：
```
每个 section 后面都配一个"挑战"段：
"尽管该方案在 X 方面表现出色，但也面临若干挑战，包括 A、B 和 C。
尽管存在这些挑战，凭借其 Y 和 Z，该方案将继续发挥重要作用。"
```

人味：
```
直接砍掉。或者最多一句：
"这个方案在 A 场景下不能用，改用 B。"
```

WHY：
"尽管...但也面临挑战...尽管存在挑战...继续..."是 AI 最经典的面面俱到句式。
统计上最安全的做法是每个观点都给正反两面——但这等于什么都没说。
人知道读者不需要你把每个方面都提一遍，需要的是"能不能用、什么时候不能用"。

记住什么：
"挑战与展望"段几乎都可以砍。如果有限制条件，一句话说清楚。
面面俱到的正反两面 = 没有取舍 = AI 味。

### 曲子 5：[有具体] 通用积极结论 vs 具体下一步

AI 味：
```
文档结尾：
"该方案代表了向正确方向迈出的重要一步。
随着技术的不断演进，激动人心的时代即将到来。
我们将继续追求卓越，为行业做出更大贡献。"
```

人味：
```
文档结尾：
"下一步：
- Q4 完成模块 A 的集成测试
- Q1 上线监控台，PSI > 0.25 告警
- 参数版本 v2 对齐监管报送格式"
```

WHY：
"重要一步""激动人心""追求卓越"是统计最可能的"积极结尾"——AI 默认以乐观收尾。
但这些词不传递任何信息——读者读完不知道下一步干什么。
人结尾给具体行动：谁、什么时候、做什么、做到什么程度。

记住什么：
结尾不要写"激动人心的时代"。写具体下一步——有责任人有时间线有验收标准。
通用积极结论 = 不传递信息 = AI 味。具体下一步 = 有行动 = 人味。
